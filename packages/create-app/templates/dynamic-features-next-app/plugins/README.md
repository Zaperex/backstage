# The Plugins Folder

This is where your own static plugins and their associated modules live, each in a
separate folder of its own. This folder is not used if plugins are installed dynamically.

If you want to create a new static plugin here, go to your project root directory, run
the command `yarn new`, and follow the on-screen instructions.

You can also check out existing plugins on [the plugin marketplace](https://backstage.io/plugins) which you can install statically or dynamically.
